## 🎮 주요 포함 게임 (5종)
1. **GIJO Slots (네온 777 슬롯머신)**:
   - `🎰 777` 2000배 배당 심볼
   - `Auto Spin (10x / 50x / ∞)`
   - `777 Jackpot Fever`
   - `Double 2x Gamble (Red/Black)`
   - `MAX BET (200 크레딧)`
   - `Gold Coin Shower FX`
2. **GIJO Block Drop (블록 쌓기)**:
   - Hold Piece, Ghost Piece, Laser Line Clear, Combo Streak (x2~x5), Speed Fever
3. **GIJO Space Shooter (비행기 슈팅)**:
   - Bomb Clear 핵폭탄, Hyper Laser 3단계, Shield 보호막, Boss 보스전
4. **GIJO Neon Snake (뱀 키우기)**:
   - Dash 부스터, Golden Apple 5x, Poison Trap, Wall Portal, Magnet Fever
5. **GIJO Brick Breaker (벽돌 깨기)**:
   - Multi-Ball 3구, Giant Paddle, Laser Cannon, Bomb Brick, Fireball 관통
